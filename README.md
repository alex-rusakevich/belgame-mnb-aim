Беларусіфікатар для гульні Mount & Blade: Агнём і мячом
===

Беларусіфікатар для гульні https://store.steampowered.com/app/48720/Mount__Blade_With_Fire__Sword/

Заснаваны на русіфікатары https://rusmnb.ru/index.php?topic=10747.0 і на шрыфце `GNU/FreeSerif`.

# Увага

Праект **вельмі** далёкі ад ідэалу. У наступныя паўгода ў мяне не будзе часу і магчымасці давершыць пераклад. Але калі вы маеце магчымасць дапамагчы праекту, адчыняйце пул-рэквест. Аднак заўважце: праект вядзецца не на тарашкевіцы, не на лацінцы, а на афіцыйнай беларускай мове.

# Геймерам

На ўкладцы Рэлізы спампуйце апошнюю версію ўстаноўшчыка, запусціце і прытрымлівайцеся інструкцый.

# Перакладчыкам

Перакладчыкам для працы неабходна праграма `poedit`. З яе дапамогай рэдагуйце файл `translation.po`.

Пераклад дасылайце як асобны пул-рэквест.

Асаблівая ўвага да тэксту, дзе ёсць па краям прабелы, напрыклад, ` и `. Прабелы ў перакладзе павінны захоўвацца.

Павінны таксама захоўвацца маркеры для праграмнай падстановы, напрыклад, `%s`, `{name0}` і г.д. 
Гульня на іх месцах падставіць сваі значэнні.

Каб усталяваць пераклад без `.exe`, патрэбна мець на камп'ютары праграмы `python>=3.14`, `poetry`.
Каманда для ўстаноўкі перакладу: 

```sh
poetry run inv install
```
